# 🧠 Deep Learning Practice

A structured, from-scratch journey through the foundations of Artificial Neural Networks (ANNs) — from a single neuron to full feed-forward networks trained on real datasets. Built to solidify core deep learning concepts (activation functions, forward/backward propagation, loss functions, gradient descent) before moving into higher-level frameworks and advanced architectures.

> 📌 Part of my broader AI/ML learning path — see my [Python_Programming](https://github.com/AbhijeetGorale/Python_Programming) repo for general Python practice and automation scripts.
